# Acetyl Client

**Acetyl Client** is the web-based chat client made by Acetyl, featuring real-time chat messaging, voice chat, and much more.  
The chat client is available directly through the web:
[https://acetyl.cc](https://acetyl.cc) or [https://acetyl.onrender.com](https://acetyl.onrender.com)

## Features

* **No Signup Needed:** Just visit acetyl.cc/client and start chatting, no signup, and completely free
* **Real-time Messaging:** Instant messaging across public and private servers
* **Custom Servers:** Create and manage private server with invite codes
* **Voice Chat:** Full private voice chats for servers
* **Direct Messaging:** DM users directly with `@username,` at the start of the message
* **File Attachments:** Upload images and files directly into the chat
